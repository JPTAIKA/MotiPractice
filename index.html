SERVER FEATURES

MOTI JPN GG の主な特徴と機能をご紹介します

アンチチート検出機能

サーバーに導入したアンチチートにより、不正ツールの使用やルール違反を自動で検知する仕組みを導入しています。

多彩なPvPキット設定

Boxing、Sumo、UHC、Vanilla、NoDebuffなど、様々なルール設定でお好みの対戦を楽しめます。

対戦リプレイシステム

対戦した試合の様子をゲーム内で再生し、自分の動きや立ち回りを後から振り返ることができます。

Ranked & Unranked マッチ

実力を競い合うレート戦（Ranked）や、気軽に遊べるカジュアル戦（Unranked）などの対戦形式を選択できます。

SERVER RULES

プレイヤー全員が楽しく、公平に遊ぶための基本ルール

01

チート行為および不正クライアントの禁止

ハッククライアント、マクロ、ダブルクリックによる異常クリック、自動化ツールなどの使用は固く禁じられています。検知された場合は永久追放（BAN）となります。

02

バグ・脆弱性の悪用禁止

ゲームのバグやマップの隙間、システムの欠陥を故意に利用した不当な有利獲得行為は禁止されています。発見した場合は速やかに管理チームにご報告ください。

03

迷惑行為・ハラスメントの禁止

チャットでの誹謗中傷、暴言、過度なスパム、ニックネーム機能の悪用によるなりすまし行為は禁止です。他のプレイヤーに敬意を持って接してください。

04

対戦の意図的な放棄・チーミングの禁止

Ranked戦での故意の敗北行為（トロール）や、対戦相手との不当な協力関係（チーミング）は処罰の対象となります。
